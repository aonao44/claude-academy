公式サンプル Q7 ・ シナリオ3 マルチエージェント調査 ・ ドメイン1（Task Statement 1.2）

視覚芸術しか残らないレポート

長い問題文を役割ごとに分け、どこで分野が消えたかを1枚の図で追います。正解は B（コーディネーターの分解が狭すぎる）。

1長い問題文は5つの役割に分けて読む

問題文は長くても、中身は「状況・証拠・症状・設問」の組み合わせです。緑の証拠が選択肢を消す材料になります。

状況

After running the system on the topic "impact of AI on creative industries,"

「AI がクリエイティブ産業に与える影響」というテーマでシステムを動かした。

証拠①

you observe that each subagent completes successfully: the web search agent finds relevant articles, the document analysis agent summarizes papers correctly, and the synthesis agent produces coherent output.

サブエージェントはどれも正常に完了した。検索担当は関連記事を見つけ、分析担当は論文を正しく要約し、まとめ担当は筋の通った出力を作った。
→ 下流の3担当は無実。A・C・D がここで消える。

症状

However, the final reports cover only visual arts, completely missing music, writing, and film production.

ところが最終レポートは視覚芸術だけで、音楽・執筆・映画制作がまるごと抜けている。

証拠②

When you examine the coordinator's logs, you see it decomposed the topic into three subtasks: "AI in digital art creation," "AI in graphic design," and "AI in photography."

コーディネーターのログを見ると、テーマを「デジタルアート」「グラフィックデザイン」「写真」の3つに分解していた。
→ 3つとも視覚芸術。最初の割り振りの時点で音楽・執筆・映画が消えている。

設問

What is the most likely root cause?

最も可能性の高い根本原因はどれか？ → 症状の対策ではなく、最初に壊れた場所を答える。

長文のコツ：最後の一文（設問）を先に読む。「root cause を聞かれている」と分かってから本文を読むと、証拠を探す目で読めます。

2どこで分野が消えたか

左から右へ仕事が流れます。灰色の点線が「割り振られなかったので誰も調べていない」分野です。

壊れた場所（根本原因） 正常に動いた（問題文が明言） 誰にも割り振られなかった分野 各選択肢が疑っている場所

3選択肢を図の上に置く

A・C・D はどれも、図で「✓ 正常」の箱を疑っています。問題文の証拠①がその箱を無実だと言っているので、残るのは B だけです。

A まとめ担当を疑う

The synthesis agent lacks instructions for identifying coverage gaps in the findings it receives from other agents.

まとめ担当には、他のエージェントから受け取った結果の抜け漏れを見つける指示がない。

✗ 音楽の資料はそもそも届いていない。抜けを見つける指示は有効な対策だが、症状を後で拾うもので、原因は直らない。

B コーディネーターを疑う

The coordinator agent's task decomposition is too narrow, resulting in subagent assignments that don't cover all relevant domains of the topic.

コーディネーターのタスク分解が狭すぎる。その結果、サブエージェントへの割り振りがテーマの関連分野をすべてカバーしていない。

✓ 正解 証拠②（ログ）がそのまま示している。分野が消えたのは最初の割り振り。

C 検索担当を疑う

The web search agent's queries are not comprehensive enough and need to be expanded to cover more creative industry sectors.

検索担当のクエリが網羅的でなく、もっと多くの分野をカバーするよう広げる必要がある。

✗ 検索担当は「写真における AI」を頼まれ、そのとおり検索した。頼まれていない音楽を検索しないのは正しい動き。

D 分析担当を疑う

The document analysis agent is filtering out sources related to non-visual creative industries due to overly restrictive relevance criteria.

分析担当が、関連性の基準が厳しすぎるせいで、視覚以外の分野の資料を除外している。

✗ 問題文は「正しく要約した」と言っている。資料を捨てた証拠はない。

4直すならどこを直すか

試験が聞いているのは「どこが壊れたか」までです。直し方は公式ガイド 1.2 に2通り出てきます。

直し方中身
コーディネーターの指示を直す割り振る前に、テーマに含まれる分野を全部挙げさせてから分けさせる。
反復改善ループを足すまとめの結果をコーディネーターが見直し、抜けた分野があれば検索担当と分析担当に追加で調べさせる。カバーが十分になるまで繰り返す。
公式ガイド 1.2 の一文がほぼ B と同じ文面です。
Risks of overly narrow task decomposition by the coordinator, leading to incomplete coverage of broad research topics
コーディネーターのタスク分解が狭すぎると、幅広い調査テーマのカバーが不完全になる、というリスク。
