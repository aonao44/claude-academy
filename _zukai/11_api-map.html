シナリオ6 ・ 1回の API 呼び出しを分解

API 呼び出しの全体マップ

messages・tools・input_schema・tool_choice・tool_use が、1回の呼び出しのどこにあるか。請求書の抽出（問題 6.1〜6.3）を例にします。

緑の枠＝文章（送る側はお願い、返る側は文章の返事） 紫の枠＝用紙（ツール・スキーマ） 灰色の枠＝設定

0階層だけ先に見る（リクエストの中身）

箱の入れ子を、フォルダのような木の形にしたものです。各行の小さい数字は深さ（数字が大きいほど内側）。紫の点線で囲んだ範囲全体が「スキーマ」です。required はスキーマの一部です。

  • 0client.messages.create(…)1回の API 呼び出し
    • 1model / max_tokens設定
    • 1systemシステムプロンプトお願いの文章
    • 1messages会話の中身お願いの文章＋文書
    • 1tools白紙の用紙の束問題 6.1
      • 2{ … }用紙1枚（extract_invoice）
        • 3name用紙のタイトル"extract_invoice"
        • 3description用紙の説明"請求書の情報を記録する"
        • この点線の中が全部スキーマ
          3input_schema欄の設計図
          • 4type: "object"「欄の集まり」という決まり文句
          • 4propertiesどんな欄があり、何を書けるか

      • 2{ … }用紙3枚目（extract_receipt）中身は同じ形

返ってくる側は、content → tool_use → input（欄の中身）。input は、上の input_schema の設計図どおりに埋まって返ります。

1名前の対応（送る側と返る側）

送るとき（リクエスト）返るとき（レスポンス）たとえ
tools の中の1枚tool_use ブロック白紙の用紙 → 記入済みの用紙
name（用紙のタイトル）name（どの用紙に書いたか）同じ名前で対応する
input_schema（欄の設計図）input（欄の中身）設計図どおりに中身が埋まる
system / messages（お願い）text ブロック（文章の返事）便箋でのやりとり

2プロンプトで直す vs 構造で直す

プロンプト（緑の枠）構造（紫の枠・tool_choice）
書く場所system・messagestools（input_schema）・tool_choice
中身お願いの文章用紙の形・返し方のルール
守られ方たいてい守られるが、破られることもあるその形でしか返せない
6.1 の例✗「例外なく JSON だけで答えよ」✓ 抽出をツールにして tool_use で受け取る
6.2 の例✗「必ずツールを使って」とお願いする✓ tool_choice: "any"
6.3 の例✗「税番号をでっち上げるな」✓ vendor_tax_id を null OK・必須から外す
試験のサイン：同じ失敗が「たまに」起きる → お願い（プロンプト）を強める選択肢は✗になりやすい。用紙の形やルール（スキーマ・tool_choice）を変える選択肢が正解になりやすい。

3コードで見ると（全部入り）

res = client.messages.create(
    model="claude-sonnet-5-5", max_tokens=1024,                       # 設定
    system="あなたは経理の抽出担当です。",                              # プロンプト
    messages=[{"role": "user", "content": "抜き出して：" + text}],      # プロンプト＋文書
    tools=[{                                                           # 用紙の束
        "name": "extract_invoice",                                     #   用紙のタイトル
        "description": "請求書の情報を記録する",                         #   用紙の説明
        "input_schema": {                                              #   欄の設計図（スキーマ）
            "type": "object",
            "properties": {
                "vendor":        {"type": "string"},
                "amount":        {"type": "integer"},
                "vendor_tax_id": {"type": ["string", "null"]}          #   6.3：null OK
            },
            "required": ["vendor", "amount"]                           #   6.3：税番号は必須から外す
        }
    }],
    tool_choice={"type": "any"}                                        # 返し方のルール（6.2）
)
data = res.content[0].input                                            # 記入済みの用紙の中身（6.1）
